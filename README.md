# Motorcycle Telemetry Logger
An ESP32-based data logger that records IMU and GPS data during rides and tracks your lean angle in real time.

## Status

Currently in development. Target: v1.0 by 2026-08-24.

## Repository Layout

- 'firmware/' - ESP32 firmware (PlatformIO)
- 'hardware/' - BOM, wiring, mount design
- 'analysis/' - Python analysis pipeline
- 'docs/' - design decisions and derivations
